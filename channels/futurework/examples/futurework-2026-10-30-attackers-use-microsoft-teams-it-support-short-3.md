# Teams wasn't hacked. That's the problem.

Microsoft Teams was not hacked, and that is exactly the problem. In the latest wave of fake IT support scams, security researchers found no software flaw at all. Attackers simply use external chat, a feature that lets people outside your company message you. Microsoft's documentation says it allows chat with every outside domain by default. Microsoft says admins can block external users and that new AI phishing detection is coming. Fair. But Arctic Wolf wrote that most organizations have no legitimate need for open, any tenant external chat. So when an employee gets fooled, the headline says someone clicked. Nobody asks who left the door open in the first place. A default is a decision, even when nobody remembers making it. Should open external chat be switched off by default?
