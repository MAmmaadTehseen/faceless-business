## Boundaries and remaining review

The source sets no overall word count, slug convention, schema type, image-alt convention, external rel values, sitemap rules or IndexNow requirement. Those are additional owner-requested SEO work. It contains no literal banned-word list; stylistic examples are not treated as exhaustive lexical bans. The production prompt keeps the pre-existing stricter ban on en dashes too.

Interactive approvals and client-service specifics are inapplicable to automated channel explainers. Local-client support needs explicit brief fields and separate configuration; it must not fabricate business details. Metadata and entities are structured fields rather than visible editorial appendices. Evidence is stored by section and rendered in place, resolving the source's separate delivery instructions. FAQ and other schema reflect visible data; no HowTo is invented.

Semantic distinctness, trustworthy sources, independent organizations beyond name/domain checks, accurate claims, relevance, natural prose, genuine local context, and whether summaries introduce new claims remain model self-review plus human editorial review. Title Case is a conservative mechanical approximation. Near-identical titles use an 85% character similarity threshold. Keyword position is measured against assembled Markdown, consistent with the existing generator. Exact phrase capitalization is checked; duplicate occurrence checks are case-insensitive.

When fewer than two published peer articles exist, the picker links available articles only; it never fabricates URLs. Existing stored articles need refresh to gain body links; the hub also computes related links dynamically. IndexNow is best effort and does not guarantee indexing. ISR may take ten minutes to expose an upsert. Static sitemap dates use the latest archive modification (or a fixed initial date), avoiding a fresh timestamp on every request; static page edits should update that baseline.

Refresh without changing articles or calling Claude: `.venv/bin/python scripts/article_refresh.py --dry-run`. Export database configuration first; this script never loads `.env`. Estimate $0.60 per failed article, up to $1.20 if retried. Regeneration requires retained `out/<content-id>/script.json`; missing scripts fail rather than inventing content. No live backfill was run.
