# Channel fonts (SIL Open Font License 1.1)

From github.com/google/fonts (ofl/), vendored so renders never fetch fonts over the network.
Variable fonts were instanced to fixed weights with fontTools (`instantiateVariableFont`, names updated);
the OFL allows modified versions under the same licence. Licence texts sit next to each family.

| channel | captions / hooks | headlines / thumbnails |
|---|---|---|
| futurework | Montserrat Black (900) | Montserrat ExtraBold (800) |
| tradewinds | Anton | Oswald Bold (700) |
| escapevelocity | Bebas Neue | Exo 2 Black (900) |
| tentongues | Poppins ExtraBold (English); Noto for non-Latin scripts | Poppins ExtraBold |
